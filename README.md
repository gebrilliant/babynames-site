# 佳名堂 · 中国宝宝起名与姓氏文化网站

一个纯静态、零依赖的中文起名与姓氏文化网站。

## 功能

1. **宝宝起名生成器**：输入父母双方姓名，可选择随父姓/母姓/父母双姓组合与宝宝性别，生成：
   - 乳名（小名）：叠字、食物系、自然系小名
   - 正式姓名（可用于身份证登记）：含每个字的寓意解读，部分名字会从父母双方姓名中各取一字，寓意「血脉相连」
   - 同样的输入总是得到同样的结果（确定性伪随机），方便分享比较
2. **姓氏起源解读**：收录王、李、张、刘、陈等 14 个主要姓氏的起源、郡望与迁徙历史，支持搜索
3. **五千年姓氏演化**：从上古八大姓到当代百家姓的时间线，含《百家姓》504 姓全文与当代十大姓氏人口图表

## 技术栈

HTML + CSS + 原生 JavaScript，无任何构建工具与第三方依赖，直接打开 `index.html` 或部署到 GitHub Pages 即可使用。所有数据与计算均在浏览器本地完成。

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```
